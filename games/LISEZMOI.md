# Jeux inclus dans l'installateur

Mets ici des applis `.nwa` dont tu as le droit de te servir : la compilation
(sur ton Mac ou dans **ta copie privée** sur GitHub) les copie dans
l'installateur et les prépare pour le slot B. Ils sont ensuite installés en
même temps qu'iOS-OS, même sur un PC Windows sans compilateur ARM.

Ne mets jamais de jeux dans le dépôt public : seulement dans ta copie privée.
